# Safety Guardrails

## Motivation
가드레일은 AI 서비스의 신뢰성 확보를 위해 에이전트 아키텍처의 입/출력을 기업 운영 정책에 맞게 제어한다. 본 프로젝트에서는 규칙 기반 가드레일과 소형 임베딩 모델 기반 가드레일로 하이브리드 방식을 채택한다.   

## Agent Trajectory-level Safety Evaluation
에이전트 궤적 수준 안전 평가는 에이전트가 복합적인 task를 수행하는 과정에서 발생하는 전체 행동 흐름(trajectory)이 안전한지, 위험 요소가 없는지 평가하는 방법이다. 
여러 step을 거치는 동안 발생하는 여러 도구 사용, api 호출 로그 추적/분석을 통해 위험 요소를 탐지한다.
